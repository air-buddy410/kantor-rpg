# Scope dan delivery
Baca PRD/PRD-v0.1.md, DESIGN.md, docs/DELIVERABLES.md dan handoff/PROMPT-CLAUDE.md sebelum mengerjakan. Kerjakan hanya repo ini, bukan operasi ISP.
Opus 5.5 High adalah pilihan pemilik; laporkan jika runtime berbeda. Paid usage, top-up, auto-reload, model substitution, merge dan deploy tidak diizinkan.
M0-M3 boleh dikerjakan, M4 private integration disabled sampai persetujuan sumber/hosting/security. Gunakan branch/PR; jangan merge ke main.
Jangan menyalin aset, source bundle atau persona Holixora/Pokemon. Tulis evidence dari hasil execution nyata. Repo public hanya sanitized original outputs. Jangan memasukkan local skills pihak ketiga sebelum lisensi diperiksa.
PDF PRD bukan gambar CAD. Native DWG hanya sah setelah generated/reopened dengan tool native legal; DXF renamed tidak sah.

## Filter mutu selama pekerjaan
Art direction ada di DESIGN.md. Antislop berlaku selama pekerjaan, bukan sesudah saja: identitas khas, alasan tiap keputusan; tidak ada klaim/testimoni angka palsu; semua target berlabel; no em dash; no template marketing cards; semua kontrol bekerja; data views loading/empty/error; DOM keyboard/focus/Escape; text contrast normal >=4.5, large >=3, controls >=3; tap targets >=44px; distinct mobile/tablet layout; reduced motion; kedua theme yang dihadirkan diuji. Hitung contrast, jangan eyeball. UI harus built/run dan walkthrough tercatat, bukan hanya screenshot atau file stub. Komentar kode menjelaskan alasan non-obvious, bukan narrate tiap baris. Skema CAD/Blender/runtime satu sumber. UI final tidak disebut selesai sebelum seluruh gate itu diuji.
